# Boardu

A free, private pin board for your notes, lists and little tools. Notes hang on themed boards (wood, cork, chalkboard, notebook, festive boards and more) and sway in a gentle wind.

**Open it:** https://shreyeahhs.github.io/boardu/

- No sign-up and no account. Everything you write stays in your own browser.
- Works offline once it has loaded, and can be installed like an app.
- Moving between computers? Back up to a file, or in Chrome and Edge keep a synced backup file in OneDrive or on a USB stick.

It is one HTML file with no build step: `index.html`, plus `sw.js` for offline use, `manifest.webmanifest` and `icon.svg`.

Designed and built by [shreyas](https://shreyeahhs.vercel.app).
